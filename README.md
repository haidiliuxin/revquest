# RevQuest · 二进制探险岛 MVP

一个面向大学生的 CTF 逆向入门网站。玩家通过四座课程小岛，逐步学会识别 Windows PE、使用 ILSpy 阅读 .NET 反编译结果、跟踪条件分支，并还原逐位置变化的 XOR。最后下载并分析一份自制 EXE，在自己的 Windows 终端运行它，从程序输出中取得 flag。

## 本地启动网站

当前项目无需安装前端构建工具：

1. 直接用浏览器打开 `index.html`；或
2. 在项目根目录运行 `python -m http.server 8000`，访问 `http://localhost:8000`。

网站会把课程进度、通关记录和笔记存入浏览器 `localStorage`。右上角重置按钮可以重新开始。

## 课程与关卡

- 四座渐进式学习小岛，每节带知识检查并按顺序解锁。
- 三道浏览器内的入门谜题，包含逐层提示和解题复盘。
- 一个最终 Windows EXE Boss：下载 PE 样本，用 ILSpy 反编译，恢复通行短语，在本机运行程序并提交其输出的 flag。
- 本地分析手记、XP 进度与完成动画。

## 工具补给站

网站新增了独立的工具环境课程，按“样本侦察 → 字节观察 → 静态分析 → 动态调试 → 本地验证”介绍常见逆向操作，并提供上游下载入口：

- Detect It Easy：识别文件格式、架构与编译器信息。
- HxD：查看十六进制 / ASCII、偏移并搜索字节或文本。
- ILSpy：反编译本项目使用的 .NET 教学程序。
- dnSpyEx：社区维护的 .NET 调试器，练习断点、单步、变量和调用栈。
- Ghidra：分析原生二进制的反汇编、反编译、函数图和交叉引用。
- x64dbg：调试 Windows 原生 x86 / x64 用户态样本。

当前 EXE Boss 需要 Windows x64、.NET 8 Runtime 和 ILSpy。工具补给站以学生自我确认的方式记录环境准备状态；网页不会检查本机已安装的软件。Ghidra 与 x64dbg 是面向后续原生程序关卡的工具，当前托管 .NET 样本优先用 ILSpy。

## EXE Boss 的运行要求

- 样本：`challenges/RevQuest.FirstSteps.exe`
- Windows x64，.NET 8 Runtime。
- ILSpy 可直接打开 .NET 程序集并查看反编译的 C#。
- 样本不联网、不读写文件，只从终端读入一行并向终端输出结果。

构建环境：Windows x64 + .NET 8 SDK。重建命令和样本说明见 [`challenges/README.md`](./challenges/README.md)。

## GSAP 动效

前端使用 GSAP 3 核心库播放页面入场、吉祥物漂浮、提示弹出和通关庆祝动画。静态页面通过 jsDelivr CDN 加载 GSAP；如果 CDN 不可用，课程和答题功能仍可使用，动画会降级为无动效。系统开启“减少动态效果”时会关闭 GSAP 动画。

## 当前范围

- 单机静态 MVP，无账号、后端或跨设备同步。
- 答案校验在前端进行，仅适合学习原型，不适合比赛或需要保密的挑战。
- 网页不会在浏览器或服务器上执行 EXE；样本由学习者下载后自行分析和运行。
- 本项目用于授权的 CTF 教学与离线练习。
